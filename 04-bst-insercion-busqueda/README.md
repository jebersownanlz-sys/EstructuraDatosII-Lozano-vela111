# Guía 4 – BST: inserción y búsqueda

Esta carpeta contiene el catálogo inteligente de productos implementado con un árbol binario de búsqueda.

- `CatalogoBST/CatalogoBST.java`: inserción, búsqueda, recorridos y métricas del árbol.
- `CatalogoBST/PruebasBST.java`: pruebas de inserción, búsqueda, duplicados y orden.
- `CatalogoBST/Experimento.java`: experimento comparativo.

Para compilar y ejecutar las pruebas, entra en `CatalogoBST`, ejecuta `javac *.java` y luego `java PruebasBST`.
